# 08 - Hashing

Hash tablosu anahtarı bir konuma dönüştürerek ekleme, arama ve silme işlemlerini ortalama `O(1)` zamanda yapar. En kötü durum çakışmalara bağlı olarak `O(n)` olabilir. `HashMap` anahtar-değer, `HashSet` yalnızca benzersiz anahtar saklar.

Alıştırmalar:

1. İki dizinin ortak elemanlarını `HashSet` ile bulun.
2. Toplamı hedef olan iki sayıyı sırasız dizide `HashMap` ile bulun.
3. Kelimeleri frekanslarına göre sıralayın.
