# 14 - Dynamic Programming

Dynamic programming, aynı alt problemlerin tekrar hesaplandığı durumlarda sonuçları saklar. İki temel yaklaşım vardır: memoization yukarıdan aşağıya, tabulation aşağıdan yukarıya ilerler.

Coin change örneği her tutar için en iyi önceki sonucu saklar. Zaman maliyeti `O(tutar × para türü)`, bellek maliyeti `O(tutar)` olur.

Alıştırmalar:

1. Fibonacci'yi memoization ve tabulation ile yazıp karşılaştırın.
2. 0/1 knapsack problemini çözün.
3. İki metnin en uzun ortak alt dizisini bulun.
