# 01 - Karmaşıklık Analizi

Big-O, girdi büyüdükçe algoritmanın çalışma miktarının nasıl arttığını anlatır. Sabit erişim `O(1)`, tek döngü `O(n)`, iç içe iki döngü çoğunlukla `O(n²)` olur. Big-O gerçek süreyi değil büyüme davranışını karşılaştırır.

Örnekte üç farklı işlem sayılır. Aynı girdide sayaçların nasıl değiştiğini gözlemleyin.

Alıştırmalar:

1. `linearSum` metodunu ek bellek kullanmadan doğrulayın.
2. `hasDuplicateQuadratic` için `HashSet` kullanan `O(n)` çözüm yazın.
3. Girdi iki katına çıktığında sayaçların kaç kat arttığını karşılaştırın.
