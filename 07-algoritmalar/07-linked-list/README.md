# 07 - Linked List

Linked list elemanları ardışık bellek yerine düğümler üzerinden bağlar. Başa ekleme ve baştan silme `O(1)`, değer arama `O(n)` sürer. Sondaki düğüm ayrıca tutulduğu için sona ekleme de `O(1)` yapılır.

Alıştırmalar:

1. Belirli bir değeri silen metot ekleyin.
2. Listeyi bağlantıları değiştirerek ters çevirin.
3. Yavaş ve hızlı işaretçiyle döngü tespiti yapın.
