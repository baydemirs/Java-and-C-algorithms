# 09 - Ağaçlar ve Binary Search Tree

Binary search tree'de her düğümün solundaki değerler küçük, sağındakiler büyüktür. Dengeli ağaçta ekleme ve arama ortalama `O(log n)`, tek tarafa yatmış ağaçta `O(n)` olur. Inorder dolaşma değerleri sıralı üretir.

Alıştırmalar:

1. Minimum ve maksimum değeri bulan metotları yazın.
2. Bir düğümü silme işlemini ekleyin.
3. Ağacın dengeli olup olmadığını kontrol edin.
