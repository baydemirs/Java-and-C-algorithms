# 16 - Union-Find

Union-Find, elemanları ayrık kümeler halinde tutar. `find` bir elemanın temsilcisini, `union` iki kümenin birleştirilip birleştirilemediğini bildirir. Path compression ve union by size ile işlemler pratikte sabite çok yakın sürede çalışır.

Kullanım alanları: bağlı bileşen takibi, çevrim tespiti ve Kruskal minimum spanning tree algoritmasıdır.

Alıştırmalar:

1. Bir graph'a kenarlar eklenirken ilk çevrimi bulun.
2. Kruskal algoritmasını uygulayın.
3. Her bağlı bileşenin elemanlarını gruplayarak yazdırın.
