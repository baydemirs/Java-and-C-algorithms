# 04 - Sıralama Algoritmaları

Insertion sort küçük veya neredeyse sıralı veride basit ve etkilidir; en kötü durumda `O(n²)` çalışır. Merge sort her durumda `O(n log n)` çalışır fakat birleştirme sırasında `O(n)` ek bellek kullanır.

Alıştırmalar:

1. Selection sort yazın ve swap sayısını ölçün.
2. Merge sort'u azalan sıralama yapacak biçimde değiştirin.
3. Java `Arrays.sort` ile süre karşılaştırması yapın.
