# 03 - Arama Algoritmaları

Linear search sırasız dizide çalışır ve en kötü durumda `O(n)` eleman inceler. Binary search yalnızca sıralı dizide çalışır ve arama alanını her adımda ikiye bölerek `O(log n)` sürede sonuç verir.

Alıştırmalar:

1. Binary search ile hedefin ilk görüldüğü indeksi bulun.
2. Hedef yoksa eklenmesi gereken sıralı indeksi döndürün.
3. Azalan sıradaki bir dizi için binary search yazın.
